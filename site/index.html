Como instalar o APK

  1. Gere o APK com gradle :app:assembleDebug em uma máquina com Android SDK.
  2. Copie app/build/outputs/apk/debug/app-debug.apk para site/downloads/drift-realista-rc.apk.
  3. Abra este site e toque em Baixar APK.
  4. No Android, permita instalação de apps de fontes desconhecidas se necessário.
